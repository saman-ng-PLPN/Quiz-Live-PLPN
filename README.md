# Quiz Live — เกมตอบคำถามเล่นพร้อมกัน

ระบบกลางให้ทุกแผนกสร้างชุดคำถามเอง แล้วเปิดเล่นพร้อมกันแบบ Kahoot
ผู้เล่นใช้มือถือ ไม่ต้องลงแอป ไม่ต้องล็อกอิน และจอใหญ่แสดงคะแนนแบบ realtime

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `schema.sql` | ตาราง สิทธิ์ และฟังก์ชันเกม ใช้รันใน Supabase |
| `index.html` | หน้าเว็บทั้งหมด (ผู้เล่น / ผู้จัด / จอใหญ่) |
| `config.js` | ค่าตั้งค่า **แก้เฉพาะไฟล์นี้** |
| `avatars.js` | รูปประจำตัวผู้เล่น 40 แบบ (SVG) |
| `keepalive.gs` | Apps Script กันโปรเจกต์ Supabase ถูกพัก |

---

## ติดตั้ง (ทำครั้งเดียว ~30 นาที)

### 1. สร้างฐานข้อมูล Supabase
1. ไปที่ supabase.com → **New project** (ตั้งชื่อเช่น `quiz-live`, Region: Singapore)
2. เมนู **SQL Editor** → New query → วางเนื้อหา `schema.sql` ทั้งไฟล์ → **Run**
3. เมนู **Project Settings → API** จดค่า **Project URL** และ **Publishable key** (หรือ `anon public`)

> ถ้าโดเมนอีเมลไม่ใช่ `princgroup.com` ให้รันเพิ่ม:
> `update app_config set allowed_domain = 'โดเมนของคุณ';` และแก้ `ALLOWED_DOMAIN` ใน `config.js` ให้ตรงกัน

### 2. เปิดล็อกอินด้วย Google (สำหรับผู้จัดเกม)
1. เข้า console.cloud.google.com ด้วยบัญชีบริษัท → สร้างโปรเจกต์ใหม่
2. **Google Auth Platform** (หรือ APIs & Services → OAuth consent screen)
   - Audience / User type: **Internal** ← จะล็อกอินได้เฉพาะบัญชีในองค์กร
3. **Clients → Create client** → ประเภท **Web application**
   - Authorized redirect URIs: `https://<project-ref>.supabase.co/auth/v1/callback`
     (ดูลิงก์นี้ได้ในหน้า Supabase → Authentication → Sign In / Providers → Google)
4. คัดลอก **Client ID** และ **Client secret**
5. Supabase → **Authentication → Sign In / Providers → Google** → Enable → วาง Client ID / Secret → Save

### 3. ขึ้นเว็บบน GitHub Pages
1. สร้าง repo ใหม่แบบ **Public** เช่น `quiz-live`
2. แก้ `config.js` ใส่ `SUPABASE_URL` และ `SUPABASE_ANON_KEY` จากข้อ 1
3. อัปโหลด `index.html` และ `config.js` เข้า repo
4. repo → **Settings → Pages** → Source: Deploy from a branch → `main` / `(root)` → Save
5. รอ 1–2 นาที จะได้ลิงก์ `https://<ชื่อบัญชี>.github.io/quiz-live/`
6. กลับไป Supabase → **Authentication → URL Configuration**
   - Site URL: ลิงก์จากข้อ 5
   - Redirect URLs: เพิ่มลิงก์เดียวกัน

> ลิงก์สั้นสำหรับผู้เล่น: ตั้ง `JOIN_URL` ใน `config.js` (ตอนนี้ใช้ Cloudflare Pages: `plpnquiz.pages.dev`)
> จอใหญ่จะแสดงลิงก์นี้และทำ QR จากลิงก์นี้เสมอ อย่าลืมเพิ่มลิงก์เดียวกันใน Supabase → Redirect URLs

> Publishable / anon key เปิดเผยในหน้าเว็บได้ ปลอดภัยเพราะข้อมูลถูกคุมด้วยสิทธิ์ (RLS) ในฐานข้อมูล
> ห้ามใส่ `service_role` / Secret key ใน `config.js` เด็ดขาด

### 4. กันโปรเจกต์ถูกพัก (แพ็กเกจฟรีพักเมื่อไม่มีการใช้ 7 วัน)
1. script.google.com → New project → วาง `keepalive.gs`
2. ⚙ Project Settings → **Script Properties** → เพิ่ม `SUPABASE_URL` และ `SUPABASE_ANON_KEY`
3. เลือกฟังก์ชัน `setup` → Run → อนุญาตสิทธิ์
   ระบบจะเรียก Supabase ทุกวัน 8 โมงเช้า ถ้าล้มเหลวจะมีอีเมลแจ้ง

## วิธีใช้

**ผู้จัด (แต่ละแผนก)**
1. เปิดลิงก์เว็บ → กด “สำหรับผู้จัด” → ล็อกอิน Google ด้วยอีเมลบริษัท
2. **+ สร้างชุดคำถามใหม่** → ใส่ชื่อเกม แผนก และคำถาม (2–4 ตัวเลือก ใส่รูปได้ ตั้งเวลาต่อข้อได้)
   แตะตัวอักษรสี ก ข ค ง เพื่อเลือกคำตอบที่ถูก
   - **รูปหน้าปก**: ใส่ได้ที่ช่องด้านบน จะแสดงบนการ์ด จอใหญ่ และมือถือผู้เล่นตอนรอเริ่ม
   - **สีคำตอบ**: กดชุดสีของแต่ละข้อ หรือแตะวงกลมสีท้ายตัวเลือกเพื่อเลือกสีเอง · ปุ่ม “ใช้สีนี้กับทุกข้อ”
   - **รูปเป็นคำตอบ**: กด 🖼 ท้ายตัวเลือก ใส่รูปอย่างเดียวหรือมีคำบรรยายใต้รูปก็ได้
3. กด **บันทึกแล้วเริ่มเกม** → เปิดหน้านี้บนโปรเจกเตอร์ → กด **⛶ เต็มจอ**
4. รอคนเข้าห้องจนครบ → **เริ่มเกม** → ระบบเฉลยเองเมื่อหมดเวลาหรือทุกคนตอบครบ
5. จบเกมแล้วกด **ดาวน์โหลดผล (CSV)** เปิดด้วย Excel ได้

- ชุดคำถามใหม่เป็น **🔒 ส่วนตัว** (เห็นเฉพาะเจ้าของและผู้ดูแลระบบ) เปิดสวิตช์ **แชร์ให้ทุกแผนก** หรือกดปุ่ม **แชร์** บนการ์ดเพื่อให้แผนกอื่นเห็น
- แท็บ **แชร์จากทุกแผนก** ดูและเล่นชุดที่แผนกอื่นแชร์ หรือกด **คัดลอกมาแก้** เป็นของตัวเอง
- แก้ไข/ลบได้เฉพาะชุดคำถามของตัวเอง (ยกเว้นผู้ดูแลระบบ)

**ผู้ดูแลระบบ** เห็น แก้ไข ลบ และเปิดเล่นได้ทุกชุด รวมชุดส่วนตัว
- ตั้งคนแรกใน Supabase SQL Editor: `insert into app_admins (email) values ('อีเมล@princgroup.com');`
- คนต่อไป ผู้ดูแลเพิ่ม/นำออกได้ที่กล่อง **⚙ ผู้ดูแลระบบ** ด้านล่างหน้ารายการชุดคำถาม
- ถ้าเผลอปิดหน้าจอใหญ่ กลับเข้าหน้าผู้จัด จะมีปุ่ม **กลับไปที่ห้อง**

**แบบทดสอบ Pre-test / Post-test**
- 👥 ผู้จัดร่วม: หน้าจัดการรอบ → กล่อง **👥 ผู้จัดร่วม** → ใส่อีเมล (ติ๊ก "ทุกรุ่นในชุด" ได้) · ผู้จัดร่วมเปิด-ปิด Pre/Post เกม Pre-test รายงาน Excel ได้ แต่ลบรอบ/แก้ผู้จัดร่วมไม่ได้ (schema.sql ส่วน 12)
- ข้อเขียน (ไม่คิดคะแนน): ในหน้าแก้ไขชุดคำถาม ติ๊ก **ข้อเขียน** ที่ข้อนั้น → ผู้ทำ Pre/Post พิมพ์คำตอบเอง เก็บไว้ในรายงาน (แท็บรายข้อ + ชีต "ข้อเขียน" ใน Excel) ไม่นับคะแนน · เกมข้ามข้อเขียนให้อัตโนมัติ (ต้องรัน schema.sql ส่วน 11)
1. ที่การ์ดชุดคำถาม กด **📝 Pre/Post** → ใส่ชื่อหลักสูตร เกณฑ์ผ่าน แบบประเมิน แล้วเลือก
   - **รอบเดียว** หรือ **หลายรุ่น** — ตัวช่วยใส่ชื่อรุ่น: *เช้า/บ่าย* · *รุ่น 1–N* · *ตามวันที่ × เช้า/บ่าย* (แก้ชื่อเองได้)
   - แต่ละรุ่นเป็นรอบแยกกัน (QR / สวิตช์ / เกม Pre-test ของตัวเอง) แนะนำ 1 รุ่นอบรม = 1 รอบ
   - หน้ารุ่นมีปุ่ม **ใช้การตั้งค่านี้กับทุกรุ่นในชุด**
   - **📊 รายงานรวมหลายรอบ**: เลือกทั้งชุดหรือติ๊กรอบเอง · ตารางเปรียบเทียบรายรอบ · เลือกดูทีละรอบได้ · ส่งออก Excel ไฟล์เดียว (มีคอลัมน์รอบ)
   - **🗑 ลบทั้งชุด** (ท้ายหน้ารายงานรวม เมื่อเลือกครบทุกรุ่นของชุด): ลบทุกรุ่นในครั้งเดียว ถ้ามีผลสอบแล้วต้องพิมพ์ชื่อชุดยืนยัน
2. หน้าจัดการรอบ: ลิงก์ `plpnquiz.pages.dev/?t=รหัส` + **แสดง QR เต็มจอ** — ใช้ **QR เดียว** ทั้ง Pre, Post และแบบประเมิน
3. **ตั้งค่าการสอบและแบบประเมิน**: สอบซ้ำได้จนผ่าน · สลับลำดับข้อ/ตัวเลือกของแต่ละคน · เลือกแบบประเมินหลังสอบผ่าน
4. ก่อนอบรมเปิด **Pre-test** · หลังอบรมปิด Pre แล้วเปิด **Post-test**
   - ผู้สอบกรอกรหัสพนักงาน ชื่อ โรงพยาบาล แผนก → ระบบตรวจสถานะแล้วพาไปขั้นที่ถูกต้องเอง
   - Post-test ไม่ผ่าน: เห็นคะแนน + **ข้อที่ผิด** (ไม่เห็นเฉลย) สอบใหม่โดยระบบจำคำตอบเดิม
   - ผ่านแล้ว: ทำ **แบบประเมิน (ไม่ระบุตัวตน)** ครั้งเดียว → จบ · ไม่แสดงเฉลยบนมือถือ
   - **🎮 Pre-test แบบเกม**: หน้าจัดการรอบ กด **เริ่มเกม Pre-test** → เปิดจอใหญ่เล่นแบบ Kahoot
     - ผู้เล่นใส่ PIN แล้วกรอกรหัสพนักงาน ชื่อ โรงพยาบาล แผนก (แทนชื่อเล่น) · เข้าได้เฉพาะก่อนเริ่มเกม
     - ระหว่างเกม **ไม่เฉลยข้อที่ถูก** ทั้งบนจอใหญ่และมือถือ แสดงแค่จำนวนคนตอบถูก/ผิด (เกมปกติยังเฉลยเหมือนเดิม)
     - จบเกม ระบบบันทึกเป็น Pre-test ให้เอง (คะแนน = จำนวนข้อที่ถูก ข้อที่ไม่ทันตอบนับเป็นผิด) · รายงานมีไอคอน 🎮
     - คนที่มาไม่ทัน: หลังจบเกมเปิดสวิตช์ **Pre-test** ให้ทำเองผ่าน QR เดิม (ไม่เป็นเกม)
5. ท้ายอบรม กด **📊 ทบทวนข้อที่ผิดบ่อย (จอใหญ่)** เรียงจากข้อที่ผิดมากที่สุด (ใช้ผล Post ครั้งแรก)
6. รายงาน: ภาพรวม · รายคน (Pre / Post ครั้งแรก / ล่าสุด / จำนวนครั้ง) · รายโรงพยาบาล-แผนก · รายข้อ · แบบประเมิน · **ส่งออก Excel**
- รายชื่อ **แผนก** และ **โรงพยาบาล** แก้ได้ที่กล่อง **⚙ ผู้ดูแลระบบ** · แต่ละรอบเลือกเฉพาะแผนกที่เกี่ยวข้องได้ · ผู้ทำมีตัวเลือก “อื่นๆ (พิมพ์เอง)”

**แบบประเมิน (📋 ในหน้าผู้จัด)**
- สร้างจากแม่แบบประเมินหลังอบรม (หลักสูตร 5 ข้อ · วิทยากร 5 ข้อ · ความคิดเห็น 2 ข้อ) แก้/เพิ่ม/ลบข้อได้
- ใช้ต่อท้าย Pre/Post Test หรือ **ใช้แบบเดี่ยว** ด้วยลิงก์ `?s=รหัส`
- **ไม่ระบุตัวตน**: คำตอบเก็บแยกจากข้อมูลผู้สอบ ไม่มีรหัส/ชื่อ/เวลาติดไป (เก็บแค่วันที่) ระบบรู้แค่ว่าใคร “ทำแล้ว”
- รายงาน: ค่าเฉลี่ย ± S.D. รายข้อ แปลผล 5 ระดับ ร้อยละพึงพอใจ (ระดับ 4–5) และความคิดเห็น

> ชุดข้อสอบที่มีเฉลย **อย่าเก็บเป็นไฟล์ใน repo นี้** (Public) ให้สร้างในหน้าเว็บหรือนำเข้าด้วย SQL ที่เก็บไว้นอก repo

**ผู้เล่น**
สแกน QR บนจอ (หรือเปิดลิงก์แล้วใส่ PIN 6 หลัก) → ใส่ชื่อ → เลือกรูปประจำตัว (สัตว์น่ารัก 20 / บุคลากร รพ. 20 · ระบบสุ่มไว้ให้ก่อน) → รอเล่น
รูปประจำตัวทั้งหมดอยู่ใน `avatars.js` เพิ่มหรือแก้รูปได้ในไฟล์นี้ไฟล์เดียว
ตอบถูกได้ 500–1,000 คะแนน ยิ่งตอบเร็วยิ่งได้มาก ถ้าเน็ตหลุดหรือรีเฟรชหน้า ระบบจะพากลับเข้าห้องเดิมเอง

## หมายเหตุทางเทคนิค
- รองรับผู้เล่นได้หลักร้อยต่อห้อง (จำกัดไว้ 300 คน)
- คะแนนคำนวณฝั่งฐานข้อมูล และผู้เล่นไม่เห็นคำตอบที่ถูกจนกว่าจะเฉลย
- รูปประกอบย่อเหลือไม่เกิน 1280px ก่อนอัปโหลด (bucket `quiz-images`)
- รัน `schema.sql` ซ้ำได้ ไม่ลบข้อมูลเดิม — ทุกครั้งที่อัปเดตเวอร์ชันให้รันไฟล์ล่าสุดอีกครั้ง
